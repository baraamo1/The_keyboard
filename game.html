Boom game
with only right and left arrow

How to play:

When you start the game, some letters bombs will throw on you and you must type the letters that throw on you before it touch you to get a point , you have only 1 min to gain points , you choose between the letters by right and left arrows and shot with enter

The rules:

  1. You can't use the cursor
  2. You can only use the left and right arrow and Enter button
  3. You must type the letters as fast as possible
  4. You have only 1 min
  5. You have to save yourself from the letters boombs before it touch you
